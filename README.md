# yoru-welcome

Экран первого запуска YoruOS.

«Welcome, как у Apple» — короткий, красивый, без 40 экранов с лицензиями.

## Будет содержать (Phase 5)

- Приветствие + выбор языка/раскладки
- Подключение к сети / Bluetooth
- Выбор темы (тёмная / светлая / custom)
- Список рекомендованных приложений (опционально)

## Стек

Планируется на **Kirigami** (Qt Quick Controls) для KDE-совместимости, либо нативный QML.
Решим после Phase 3, когда будет понятен общий стек.
